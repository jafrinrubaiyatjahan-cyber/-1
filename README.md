# 별찍기 (Pattern Drawing) - 모래시계

## 1. 과제 설명
사용자로부터 모래시계의 높이인 홀수 N을 입력받아,
입력한 크기에 맞는 모래시계 모양을 출력하는 C언어 프로그램을 작성하였다.

## 2. 소스코드

```c
#include <stdio.h>

int main() {
    int n;
    int i, j;

    scanf_s("%d", &n);

    for(i = 0; i <= n / 2; i++) {
        for(j = 0; j < i; j++) {
            printf(" ");
        }

        for(j = 0; j < n - 2 * i; j++) {
            printf("*");
        }

        printf("\n");
    }

    for(i = n / 2 - 1; i >= 0; i--) {
        for(j = 0; j < i; j++) {
            printf(" ");
        }

        for(j = 0; j < n - 2 * i; j++) {
            printf("*");
        }

        printf("\n");
    }

    return 0;
}
```

## 3. 코드 설명

### 변수

- `n` : 사용자가 입력하는 모래시계의 높이
- `i` : 행(row)을 나타내는 변수
- `j` : 공백과 별의 개수를 세는 변수

### 입력

```c
scanf("%d", &n);
```

사용자로부터 홀수 N을 입력받는다.

### 상단 부분

```c
for(i = 0; i <= n / 2; i++)
```

모래시계의 위쪽 부분을 출력한다.

행이 내려갈수록 공백은 1개씩 증가하고,
별은 2개씩 감소한다.

```c
for(j = 0; j < i; j++) {
    printf(" ");
}
```

`i`의 값만큼 공백을 출력한다.

```c
for(j = 0; j < n - 2 * i; j++) {
    printf("*");
}
```

`n - 2 * i`만큼 별을 출력한다.

### 하단 부분

```c
for(i = n / 2 - 1; i >= 0; i--)
```

모래시계의 아래쪽 부분을 출력한다.

위쪽 부분과 반대로 행이 내려갈수록 공백은 감소하고,
별은 2개씩 증가한다.

## 4. 실행 결과

